# Agent Training Orchestration

## Workflow

1. Start from the agent's role, desk, tools, and decision authority.
2. Assign only skills that change the agent's behavior or quality checks.
3. Give each agent one primary skill, supporting skills, a drill, and a success metric.
4. Avoid giving order authority to research agents.
5. Use post-market scorecards and specialist memory to update lessons.
6. Keep training guidance concrete: evidence to collect, blockers to check, and output schema to improve.

## Training Outputs

- Agent name.
- Department or desk.
- Primary skill.
- Supporting skills.
- Practice drill.
- Success metric.
- Promotion or demotion trigger.

## Review Cadence

- Before market: check role-specific data readiness.
- During market: monitor blockers and handoff quality.
- After market: score each agent by outcome evidence, not prose quality.
- Weekly: demote noisy skills and promote measurable ones.
